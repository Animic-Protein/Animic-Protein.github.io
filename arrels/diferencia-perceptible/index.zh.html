可感知的
差异。

差异不只是某种事物发生了变化。只有当变化进入一种关系，并影响我们听到什么、记住什么、期待什么或接下来能做什么时，它才变得可察觉。

科普文章 · Anímic Protein (AP)

一句话定义：在 Còdex 中，可感知差异指两种形态、时刻或存在之间一种可由某个感知系统察觉、并改变其关系解读的感官、情境或关系变化。

它究竟是什么？

一个标记可以移动，却没有人注意到。两幅图像之间存在物理差异；但要让这种差异变得可感知，它必须与注意、情境、记忆或期待发生联系。因此，它既不是物体孤立的属性，也不能证明所有人都看到了同一件事。

Còdex 将常被混为一谈的三个时刻区分开来：变化确实存在；某个人或某个系统察觉到了它；变化改变了我们对某种关系的理解。第三步不会自动发生。可检测到的差异未必产生新的关系，也未必要求采取行动。

这个概念从何而来？

在 Còdex 中，这个概念源于一个设计问题：究竟发生了什么变化？我们需要什么条件才能察觉它？神经科学有助于提出这个问题，但它既不是这一概念的作者，也没有给出唯一答案。

在一项关于视觉变化的经典研究中，Rensink、O’Regan 和 Clark 交替呈现一个场景及其修改版本，并在两者之间短暂插入空白画面。即便变化很大，参与者也可能需要一段时间才能找到；口头提示则能加快发现过程。这说明注意和任务会影响什么变得显眼，并不意味着感知本身有缺陷。另一项研究中，Yabe 及其同事记录了重复音序中省略音符时听觉皮层的反应：大脑可以对预期中的缺席作出反应。然而，对省略的神经反应不等于有意识地注意到它，也不等于从中发现了创造性意义。

因此，可感知差异并不存在于某一个单独的“脑区”。这里说的是一种分布式功能：选择、比较、让某种形态在记忆中保持足够久以便对照，并重新审视变化在其情境中的意义。

它会让人有什么感受？

它没有一种普遍的感受。有时，声音回来时，先前的空缺才变得可听见；有时，一个图形突然退到背景，一个细节显得“有些不对劲”，或者我们平静地发现对自己而言一切如旧。它也可能完全没有被注意到。体验因人、感官通道、注意力、时刻和期待而异。

因此，Còdex 不会纠正说“我没有察觉到”的人，不会把不确定当成错误，也不会把一种感受解释成诊断。更有用的问题是：你注意到了什么？是在什么条件下？还有什么仍不清楚？

它何时会变得有生成力？

Còdex 区分可感知差异——能够被察觉的变化——与有生成力的差异——能够开启一种关系、问题或可能性的变化。幽影痕迹可以让一种仍持续影响回返的缺席显现出来。这些概念本身都不授权任何转化。

以音乐为例：反复演奏 D–F–A；有一次省略 F；然后回到 D–F–A。回返时音符没有改变，但空缺可能改变了聆听。回返不一定“更好”，也不一定对每个人都不同；它只是邀请我们进行比较。

哪些布置可以支持它？

每当我们识别一种认知功能，都不需要新增一个器官。我建议扩展现有布置，加入五种小型操作，并为每种操作提供软件支持：

  • ATTENTIO · 引导注意：选择观察形态、位置或关系。聆听之玫瑰（Rosa de l’Escolta）已经提供这种方向；实验室让它变得明确。
  • RETENTIO · 保留短暂参照：呈现起点，引入间隔，再回到起点。这是本次体验中的比较记忆，不是隐藏的历史记录。
  • DISCRIMEN · 不评分地对照：区分缺席、位移和关系变化。只有参与者作出回应之后，软件才揭示预先设定的具体变化。
  • QUIES / REOBSERVE · 暂停：允许停止、再次观察或说“我不知道”。体验不会奖励以转化作为结局。
  • METACOGNITIO · 区分观察与解释：先问“我注意到了什么？”然后，如果参与者愿意，再问“这可能意味着什么？”系统不会替人回答第二个问题。

这些名称是对布置的提议，不是诊断，也不是新的规范性组件。它们延伸了已经认可的语法：记录负责文档化 → 体验负责执行 → 人负责决定 → 只有得到授权时 MUTATIO 才进行转化 → 回返保留 provenance（来源与过程记录）。

Còdex 的布置如何变成可操作的？

布置不是命令，也不是替人作决定的按钮。它准备一组条件，并让感知与行动之间的门槛保持开放：

信号 → suggestedImpulse（一项提议）→ 人的决定 → 获授权的行动 → provenance（来源记录）

在实验室中，这个过程由参与者手动完成：起点 → 间隔 → 变化 → 回返 → 描述 → 对照。每一步都可以停止。如果差异不够清楚，REOBSERVE（再次观察）或 QUIET（暂停、消散）都是有效路径。只有参与者明确点击导出，才会生成 JSON 记录；它保存在本地、可撤回且不具规范性。这里不会触发 MUTATIO。

来源与边界

这些研究启发了两种演示条件——视觉变化中的注意，以及听觉省略中的期待；它们并不能证明 Còdex 的全部理论。感觉运动视觉理论是一种有影响力的学术解释，并非对大脑的最终描述。实验室是一种教学体验，不是临床工具，也不衡量个人表现。
