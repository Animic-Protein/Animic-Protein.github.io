# MUTATIO · History Tales — tractament steampunk 1939 v1.0

Paquet de preservació creat el 21 de setembre de 2026 per a Anímic Protein · Còdex Viu.

## Regla de custòdia

Les versions steampunk són variants derivades. No substitueixen els originals. Totes dues capes han de coexistir i conservar la seva procedència.

## Tractament canònic

- Retrofuturisme de 1939 amb steampunk elegant i funcional.
- Llautó, coure oxidat, reblons, engranatges, tubs, vàlvules i vapor.
- Blau cobalt líquid, ocre, verd arsènic i accents mínims de roig cotxinilla.
- Mecanismes vinculats al sentit narratiu de cada peça, no decoració gratuïta.
- Composició, textos, identitat AP i context històric preservats.
- Edison només com a memòria o homenatge pòstum; mai com a assistent viu el 1939.
